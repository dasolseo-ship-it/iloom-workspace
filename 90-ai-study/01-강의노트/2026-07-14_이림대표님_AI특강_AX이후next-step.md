## 1. Claude Code CLI의 강점

- **MCP + CLI** 연결로 말로만 업무 처리 가능

- 설치 이후 구글 연동, 스킬 포함 → 언어 없이 실무 적용 가능

## 2. 일의 6걸음 프레임워크

모든 지식노동은 이 순서로 이루어진다:

| # | 단계 | 설명 |
|---|------|------|
| 1 | **모은다** | 정보를 한 곳에 수집 |
| 2 | **가른다** | 중요한 것과 아닌 것 분류 |
| 3 | **제자리에 둔다** | 일정→캘린더, 할일→목록, 고객→CRM |
| 4 | **돌아본다** | 빠진 것, 멈춘 것 점검 |
| 5 | **한다** | 제자리에 둔 것을 실행 |
| 6 | **기록한다** | 배운 것을 남긴다 |

> 핵심: 필요할 때 AI를 부르는 게 아니라, **일이 굴러가는 판 자체를 AI 위에 올린다**

막히는 지점은 사람마다 다르다:
- "자꾸 놓쳐" → 모으기 실패
- "쌓인 건 아는데 들여다보기 싫어" → 가르기 실패
- "정리는 했는데 일이 안 나가" → 하기 싫은 것

## 3. 이림 대표님 실제 워크플로우 시연

### 메일 처리 자동화
1. **리플라이 체크** 스킬 → 회신 필요한 메일에 빨간 라벨 자동 부착
2. **인바운드 리플라이** 스킬 → 메일 유형별 자동 회신 초안 생성
   - 파이프라인 현황 체크
   - 구글 캘린더 비어있는 슬롯 확인
   - 문의 유형별 템플릿: 탐색형 / 구체적 요청형 / 레퍼런스 경유형 / 소규모 팀 개인 참여형 / **운영 방식 부적합형 (정교한 거절)**
3. **컨트랙트 닥스** → 계약서 자동 생성
4. **택스 인보이스** → 세금계산서 발행

> "얘가 다 만들어 오면 '그래 보내도 돼 / 안 돼'만 판단한다"

### 정보 수집 자동화 (모닝 루틴)
- **텔레그램-문자 동기화**: 수신 문자를 텔레그램으로 가져와 Claude가 읽음
- **카카오 리드 스킬**: PC 카카오톡 내 대화 내용 전체 추출 (서버 접근 없이)
- **임박스 트리아즈 스킬**: 카톡+문자 중 미처리 분류
  - 회신 필요 → 분리
  - 청구 알림, 카드 보안 문자, 이미 종결된 대화 → 자동 처리
- 결과: **일정 → 캘린더 / 할일 → 투두 / 고객 대화 → 진행 현황**으로 자동 분류

## 4. LLM 위키 시스템

### 개념
- `30-knowledge/위키/` 폴더에 지식을 자동 누적
- 세션 종료마다 "위키에 업데이트해라" → 자동 항목화 및 저장
- 비슷한 내용은 기존 파일에 병합, 새 내용은 새 파일 생성

### 작동 방식
1. **위키 인제스트 스킬** (넣기): 회의/대화 내용 → 위키 자동 반영
2. **인덱스 파일**: LLM이 먼저 인덱스 확인 → 관련 항목 탐색 → 서브 파일 읽기
   - 일의 철학 / 고객 관점 / 컨설팅 맥락 / 실행 설계 / 1인 비즈니스 설계 등 카테고리
3. 대화할수록 맥락이 쌓여 AI가 더 잘 이해하는 구조

> "어제 정리한 내용을 처음부터 설명하지 않아도 된다"

## 5. 조직 관점의 변화

### 관리의 역할 변화
- 지난 2000년간 관리자의 핵심 기능 = **정보 라우터** (정보를 퍼뜨리기 위한 위계)
- AI로 정보 공유가 민주화 → 위계의 정보 전달 기능이 소멸

### 조직에 남는 3종류의 인재
1. **직접 만드는 사람** (Individual Contributor): 직군 무관, 손으로 결과물을 만드는 사람
2. **DRI** (Directly Responsible Individual): 결재 없이 스스로 정하고 위에 보고만 하는 사람
3. **실무형 매니저**: 일도 하면서 동료도 함께 이끄는 사람

> "지시만 하거나 방향만 내는 사람은 이제 어려워진다. 내가 하는 게 빨라서 그냥 내가 하고 말지가 점점 생긴다."

## 6. 감각과 밀도에 대하여

- 감각은 **사후적**으로 생긴다 — 하다 보면 어느 날 전체가 보이는 시점이 온다 (운전 비유)
- 밀도 있는 경험이 중요: 막연히 보는 것과, 특정 목적으로 디깅하는 것은 다르다
- AI로 압축한 시간을 **더 많은 경험과 감각적 영역**에 투자하는 것이 핵심
- 연결 지점 찾기: 하나를 볼 때 다른 것과 연결하는 습관 → 새로운 기획 발생
