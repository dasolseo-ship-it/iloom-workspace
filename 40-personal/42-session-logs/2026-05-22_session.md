## 주요 결정사항 및 탐색 내용

### 매칭 방향
- **오프라인 취소 수주** → 동일 고객이 **온라인 수주**를 했는지 확인하는 방향

### 온라인 데이터 소스
- 공식몰, 네이버, 29CM, 씨제이몰 등 다양
- 모두 ERP 수주관리에서 **실적대리점**으로 구분 가능
- 온라인 수주는 AN컬럼(쇼핑몰주문번호)에 ORD번호 포함
- ORD번호는 오프라인 수주와 직접 연결되지 않음 (별개 데이터)

### ERP 엑셀 Export 분석 결과
| 데이터 | Export 포함 여부 |
|--------|----------------|
| 납품처주소 | ✅ 포함 (동까지 확인 가능) |
| 이름(건명) | ✅ 수주건명에서 확인 가능 |
| 쇼핑몰주문번호 | ✅ 온라인 건에만 포함 |
| 휴대폰번호 | ❌ 미포함 |
| 품목 정보 | ❌ 미포함 |

### 매칭 키 확정
- `이름 + 주소(동까지) + 휴대폰 뒷 4자리`
- 휴대폰번호만으로는 부족, 뒷 4자리는 **선우님이 구할 수 있다고 함**
