## 제도 도입 배경

최근 일룸 온라인 행사 기간 중, 오프라인 매장에서 이미 상담·수주가 진행된 고객이 동일 품목을 온라인으로 재결제하여 오프라인 수주가 취소되는 사례가 발생하고 있습니다.

이에 **2026년 영업지원제도(품의26-03-00266)**에 **매출기여 보전 조항**이 신설되어, 온라인 행사로 인해 취소된 오프라인 수주에 대해 대리점의 매출 기여를 인정하고 보전금을 지급합니다.

## 보전 대상 기준

아래 조건을 **모두 충족**하는 경우 보전 대상으로 인정됩니다.

| 항목 | 기준 |
|------|------|
| 수주 등록 시점 | 온라인 행사 공지일 **전일(D-1)까지** 등록된 수주건 |
| 취소 사유 | 해당 온라인 행사 기간 중 취소된 건 |
| 고객 동일 여부 | 고객명 + 거주 동(洞) + 휴대폰 뒷 4자리 **3가지 일치** |
| 품목 동일 여부 | 동일 시리즈 + 동일 품목 타입 (사이즈·색상 차이는 인정) |
| 납기 기준 | 행사 종료일로부터 **1개월 이내** 납기 완료 |
| **보전율** | 온라인 결제액의 **5%** |

### 품목 인정 기준 상세

| 케이스 | 인정 여부 |
|--------|-----------|
| 쿠시노 1200 ↔ 쿠시노 1400 (사이즈만 다름) | ✅ 인정 |
| 옷장 ↔ 옷장 (같은 시리즈, 구성만 다름) | ✅ 인정 |
| **쿠시노 ↔ 쿠시노코지** | ❌ 불인정 |
| **로이 ↔ 로이모노** | ❌ 불인정 |
| 모션형 책상 ↔ 다리형 책상 | ❌ 불인정 |
| 완전히 다른 시리즈 | ❌ 불인정 |

## 어떻게 추려지는가 — 매칭 프로세스

대리점에서 별도로 신청하실 필요가 없습니다. 본사에서 데이터를 수집하여 자동으로 처리합니다.

```
① 행사 등록
   └─ 본사가 온라인 행사 정보 시스템에 등록

② 데이터 수집 (행사 종료 후)
   └─ 행사 기간 내 오프라인 취소건 + 온라인 수주건 자동 추출

③ 고객 자동 매칭
   └─ 고객명 + 거주 동(洞) + 휴대폰 뒷 4자리로 동일 고객 특정

④ 품목 자동 검증
   ├─ 완전 일치 → 자동 인정
   ├─ 시리즈·품목 동일, 세부 사양 상이 → 담당자 확인 후 결정
   └─ 시리즈 불일치 → 자동 불인정

⑤ 보전금 산정
   └─ 인정된 품목의 온라인 결제액 합계 × 5%

⑥ 결과 통보 → 이의제기 접수 → 정산
```

## 기존 진행건 소급 적용

**2026년 5월 1일 이후** 발생한 취소건부터 소급 적용됩니다.

이미 종료된 행사에서 발생한 취소건도 위 기준에 해당하면 보전 대상으로 처리되며, 소급 적용 결과는 행사별로 별도 통보드립니다.

---

## 정산 방식 및 시기

| 구분 | 내용 |
|------|------|
| **납기 인정 기한** | 행사 종료일 기준 **1개월 이내** 납기 완료건에 한함 |
| **정산 시점** | 납기 완료 확인 후 **익월** 정산 |
| **지급 방식** | 위탁수수료 형태로 지급 |
| **부가가치세(VAT)** | 보전금액의 10% **별도** — 세금계산서 발행 기준 |
| **정산 단위** | 행사별 1회 처리 (월별 반복 정산 아님) |

> **예시**  
> 온라인 결제액 1,000,000원 취소건 인정 시  
> → 보전 공급가액: 1,000,000원 × 5% = **50,000원**  
> → 부가가치세: 50,000원 × 10% = **5,000원**  
> → 위탁수수료 세금계산서 합계 금액: **55,000원**  
>
> 행사 종료일 5월 24일 → 납기 인정 기한 6월 24일  
> 6월 24일 이전에 납기가 완료된 건 → **7월 정산**

## 결과 확인 방법

현재 보전 내역을 확인할 수 있는 시스템을 개발 중입니다.

- **시스템 오픈 전**: 행사별 결과를 엑셀 파일로 개별 전달
- **시스템 오픈 후**: 매장별 보전 현황 대시보드에서 직접 확인 가능 (2026년 하반기 예정)

## 이의제기 안내

결과 통보 후 내용에 이견이 있는 경우 담당 영업관리자에게 이의를 제기할 수 있습니다.

| 항목 | 내용 |
|------|------|
| **이의제기 기한** | 결과 통보 후 **14일 이내** |
| **제기 방법** | 담당 영업관리자에게 연락 (이메일 또는 커넥트플러스) |
| **필요 자료** | 해당 수주 관련 증빙 (고객 상담 이력, 수주서 등) |
| **반영 시점** | 이의제기 확인 및 검토 후 **익월 정산에 반영** |

> 이의제기가 인정되는 경우: 시스템상 미매칭된 건이나 담당자 직접 확인(호수 확인 등)으로 동일 고객임이 소명된 경우

## 자주 묻는 질문 (FAQ)

**Q. 대리점에서 별도로 취소 사실을 신고해야 하나요?**  
A. 아니요. 본사에서 데이터를 자동 수집하므로 별도 신청이 필요하지 않습니다.

**Q. 부분 품목만 일치하는 경우 어떻게 되나요?**  
A. 인정된 품목 금액 기준으로만 5% 보전금이 산정됩니다. 불인정 품목은 보전에서 제외됩니다.

**Q. 납기가 늦어져 1개월 기한을 넘길 것 같습니다. 어떻게 하나요?**  
A. 담당 영업관리자에게 사전에 연락해 주세요. 납기 초과 시 해당 건은 보전 대상에서 제외되므로, 납기 일정 관리에 유의해 주시기 바랍니다.

**Q. 이미 종료된 행사건은 언제 통보받나요?**  
A. 소급 적용 결과는 시스템 검증 후 행사별로 순차 통보드릴 예정입니다. 별도 일정 공지를 참고해 주세요.
