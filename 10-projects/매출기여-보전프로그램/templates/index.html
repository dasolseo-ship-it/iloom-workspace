운영 프로세스

1
행사 등록
커넥트플러스 공지 확인 → 시스템에 행사 입력 (공지일, 기간, 품목)
2
ERP 수주 데이터 업로드
ERP에서 해당 기간 수주 내역 엑셀 추출 → 시스템 업로드
3
취소건 자동 분류
수주번호 suffix로 순수취소 vs 납기변경 자동 구별 → 순수취소만 보전 후보
4
1차 고객 매칭 (자동)
고객명 + 동(洞) 주소로 오프라인 취소 고객 = 온라인 주문 고객 여부 확인
5
2차 품목 검증 (반수동)
매칭 카드에서 오프라인 취소 품목 입력 → 행사 품목과 자동 비교 → 인정 / 부분인정 / 불인정
6
보전금 산출 + 엑셀 출력
인정 품목 금액 × 5% → 매장별 집계 + 위탁수수료 엑셀 자동 출력

인정 기준

✓ 수주 기간: 커넥트플러스 공지 전날 ~ 온라인 행사 마지막날 사이 수주 입력된 건
✓ 동일 시리즈 + 동일 품목이어야 인정
✓ 플랫폼 조건: 행사 진행 플랫폼 주문건만 인정 (네이버 행사 → 네이버 주문건만)
✓ 납기 조건: 행사 종료일 기준 D+3개월 이내 납기건만 인정
예외 (동일 시리즈 불인정)
쿠시노 ≠ 쿠시노코지 로이 ≠ 로이모노
