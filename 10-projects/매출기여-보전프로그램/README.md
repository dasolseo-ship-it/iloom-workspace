# 매출기여 보전 프로그램

## 개요
온라인 행사로 인해 취소되는 오프라인 수주건을 보전해주는 2026년 영업지원제도 "매출기여" 프로그램 관리 시스템.

## 정책 요약 (품의26-03-00266)
- **보전율**: 고객 결제액의 **5%** 지급
- **대상**: 커넥트플러스 공지사항에 등록된 온라인 행사로 인한 취소건
- **등록 기준**: 행사 공지 **D-1일 전까지** 등록된 수주 건
- **인정 기준**: **동일 시리즈 + 동일 품목**만 인정
- **예외**: 쿠시노 ≠ 쿠시노코지, 로이 ≠ 로이모노
- **적용 기간**: 2026-05-01 ~ 2027-05-31

## 실행 방법
```bash
cd 10-projects/매출기여-보전프로그램
pip install -r requirements.txt
python app.py
# → http://localhost:8000 접속
```

## 기능
1. **행사 관리** — 커넥트플러스 행사 등록 (Excel 업로드 or 수동 입력)
2. **수주 입력** — 취소된 오프라인 수주 입력 + 자동 매칭
3. **결과 조회** — 인정/불인정/부분인정 결과 및 보전금액 집계
