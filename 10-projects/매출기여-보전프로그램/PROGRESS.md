## 2026-05-19 — 킥오프 회의 (서다솔 × 김선우)

### 의사결정 사항

| 결정 | 내용 |
|------|------|
| 업무 분장 | 서다솔 80% 실행 주도, 김선우 어드바이저 |
| 커넥트플러스 데이터 처리 | 비정형(이미지/텍스트) → **구글 시트**로 수동 데이터화 |
| 고객 매칭 키 | 휴대폰 뒷 4자리 + 고객명 + 동 주소 (3개 조합) |
| 결과물 형태 | 대시보드(웹) + 위탁수수료 엑셀 출력 |

### 데이터 소스 확정

**① ERP 수주 데이터 필드**
- 수주건명, 수주일자, 고객명, 휴대폰 뒷 4자리
- 동(洞) 주소 (상세 주소는 개인정보로 제한됨)
- 수주품목, 납기일, 대리점, 소비자가

**② 온라인 행사 데이터 필드**
- 공지일자, 행사일자, 행사품목, 할인혜택

### 핵심 이슈 발굴

1. **취소건 정의 복잡성**
   - ERP에서 납기 변경 시에도 원수주가 취소로 처리됨
   - 진짜 취소 vs 납기변경 구분 로직 필요
   - → 실제 ERP 취소 데이터 샘플 확인 후 기준 정의

2. **고객 매칭 키**
   - 상세 주소는 개인정보 제한으로 접근 불가
   - 동 주소 + 이름 + 휴대폰 뒷 4자리로 특정
   - 키 조합이 많아질수록 모수 감소, 정확도 증가 → 균형점 필요

3. **5% 계산 기준**
   - 수주 시점 기준 vs 납기 시점 기준 → 미결정
