# 회의록 정리 스킬

회의 텍스트를 받아 **회의요약 / 핵심결정 / 액션아이템 / 다음단계** 4단 구조로 빠르게 정리합니다.  
긴 음성 파일 변환이 필요하면 `transcript-organizer` 스킬을 사용하세요.

---

## 언제 사용하나요?

- 회의 후 내용을 메모해 둔 텍스트가 있을 때
- 카카오톡 대화나 슬랙 스레드를 회의록으로 정리할 때
- 이미 텍스트화된 회의 내용을 구조화하고 싶을 때

---

## Phase 1: 입력 받기

사용자가 제공하는 방식은 3가지:

| 방식 | 예시 |
|------|------|
| 텍스트 직접 붙여넣기 | 대화 내용을 메시지에 포함 |
| 파일 경로 | `C:\Users\...\회의메모.txt` |
| 파일 경로 없이 요청 | 경로를 먼저 물어볼 것 |

**파일 경로가 주어진 경우**: Read 툴로 파일 읽기  
**텍스트가 주어진 경우**: 바로 Phase 2 진행

---

## Phase 2: 컨텍스트 확인

분석 전에 다음 2가지만 간단히 확인:

1. **회의 날짜** — 모르면 오늘 날짜 사용
2. **회의명 / 주제** — 모르면 내용에서 유추

> 긴 질문 목록 없이 한 번에 물어볼 것. 사용자가 "넘어가" 또는 생략하면 기본값으로 진행.

---

## Phase 3: 4단 구조로 분석

회의 텍스트 전체를 읽고 아래 4개 섹션으로 분류:

### 0. 회의 요약 (Summary)
- 회의 전체 맥락을 **3~5문장**으로 요약
- "무엇을 논의했고, 어떤 방향으로 흘렀는가"를 중심으로
- 세부 내용이 아닌 흐름과 결론 위주로 작성

### 1. 핵심결정 (Key Decisions)
- 이 회의에서 **확정된 것**만 작성
- "~로 하기로 했다", "~확정", "~승인" 등의 표현 포착
- 결정 주체가 있으면 괄호로 표기: `(김팀장 결정)`
- 없으면 생략

### 2. 액션아이템 (Action Items)
각 항목은 아래 포맷으로 작성:

```
- [ ] [담당자] [해야 할 일] — [마감일 또는 "미정"]
```

- 담당자 불명확 시: `[미정]`
- 기한 언급 없으면: `— 미정`
- "검토", "확인", "공유" 같은 동사 포함해서 구체적으로

### 3. 다음 단계 (Next Steps)
- 다음 회의 일정 또는 후속 미팅 안건
- 아직 결정되지 않아 추가 논의 필요한 사항
- 공유/보고 일정

---

## Phase 4: 출력 형식

```markdown
# 회의록: [회의명]
**날짜**: YYYY-MM-DD  
**작성**: Claude (meeting-minutes)

---

## 회의 요약

[3~5문장. 무엇을 논의했고 어떤 방향으로 결론났는지]

---

## 핵심결정

1. [결정 내용] (결정 주체)
2. [결정 내용]

---

## 액션아이템

- [ ] [담당자] [할 일] — [마감]
- [ ] [담당자] [할 일] — [마감]

---

## 다음 단계

- [다음 회의 일정 또는 후속 안건]
- [추가 논의 필요 사항]
```

---

## Phase 5: 저장 여부 확인

정리가 끝나면 묻기:

```
저장하시겠어요?
- Y → 저장 경로 입력받아 파일 저장
- N → 출력만 하고 종료
```

**기본 저장 경로**: `20-operations/22-meetings/YYYY-MM-DD_[회의명].md`

---

## 작성 원칙

- **과도한 요약 금지**: 결정사항과 액션아이템은 원문 표현에 가깝게
- **애매한 것은 다음단계로**: "논의 필요", "검토 예정" 등은 핵심결정이 아님
- **없으면 "없음"**: 섹션이 비어도 "해당 없음"으로 표기하고 생략하지 않음
- **담당자 추론 금지**: 텍스트에 없으면 "미정"으로 표기

---

## 사용 예시

```
사용자: "오늘 팀 회의 내용 정리해줘"
[텍스트 붙여넣기]

Claude:
1. 날짜/회의명 확인 (한 줄 질문)
2. 3단 구조 분석
3. 마크다운 출력
4. 저장 여부 확인
```
