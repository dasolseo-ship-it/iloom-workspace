# 담당 매장 실적 모니터링 대시보드

## 목적

담당 11개 매장의 수주 실적을 주차별로 추적하여, 부진 매장 조기 파악 및 대응 의사결정을 지원한다.

## 담당 매장

| 매장 | 유형 | 지역 |
|------|------|------|
| 현대목동 | 입점BS (신설) | 서울 |
| 롯데영등포 | 입점BS | 서울 |
| 부천3 | B | 경기 |
| 김포5 | B | 경기 |
| 신세계시흥2 | 투자형B | 경기 |
| 인천중앙2 | B | 경기 |
| 롯데구리 | 입점BS | 경기 |
| 송도5 | 투자형B | 경기 |
| 롯데인천2 | 입점BS | 경기 |
| 인천검단 | 투자형B | 경기 |
| 의정부8 | B | 경기 |

## 대시보드 파일

- `dashboard.html` — 브라우저에서 바로 열기
- `generate.ps1` — Excel 파일에서 대시보드 재생성 스크립트

## 데이터 소스

- ERP 수주 현황 Excel (`grd_list_YYYYMMDDHHMMSS.xlsx`)
- 컬럼: 실적대리점(6), 주문일자(11), 수주금액(19)

## 업데이트 방법

```powershell
# PowerShell에서 실행
.\generate.ps1 -ExcelPath "C:\path\to\grd_list_*.xlsx"
```
