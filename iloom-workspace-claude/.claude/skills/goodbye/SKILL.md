# Goodbye Skill

> 세션 종료 시 대화 요약 저장 → 데일리노트 기록을 한 번에 자동 처리

## 자동 트리거 키워드

- "굿바이"
- "goodbye"
- "오늘 끝"
- "마무리"
- "퇴근"
- "세션 종료"
- "작업 끝"

## 3단계 자동 동작

### Step 1: 대화 요약 MD 저장

**위치**: `40-personal/42-session-logs/YYYY-MM-DD_session.md`

**내용**:
- 이번 대화에서 수행한 작업 목록
- 주요 결정사항
- 생성/수정한 파일 목록
- 미완료 작업 (있으면)

**파일 형식**:
```markdown
# YYYY-MM-DD 세션 기록

> 날짜: YYYY-MM-DD
> 시간: HH:MM 종료

---

## 수행한 작업

1. [작업1 설명]
2. [작업2 설명]
...

## 주요 결정사항

- [결정1]
- [결정2]

## 생성/수정한 파일

- `파일경로1` - 설명
- `파일경로2` - 설명

## 미완료 작업

- [ ] 작업1
- [ ] 작업2

---

#session-log #YYYY-MM-DD
```

**규칙**:
- 같은 날 여러 세션이면 기존 파일에 `## 세션 2 (HH:MM)` 섹션 추가
- 폴더 없으면 자동 생성
- 대화 내용을 기반으로 **실제 수행한 작업만** 기록 (계획이 아닌 결과)

### Step 2: 데일리노트 업데이트

**위치**: `40-personal/41-daily/YYYY-MM-DD.md`

**동작**:
1. 파일 없으면 daily-note-template.md 기반으로 생성
2. `## 오늘의 업무` > `### 완료` 섹션에 수행한 작업 추가
3. 미완료 작업은 `### 진행 중` 섹션에 추가
4. `## 오늘 배운 것 (AI 활용)` 섹션에 주요 배움 추가 (있으면)

**규칙**:
- 기존 내용 절대 삭제하지 않음 (추가만)
- 중복 항목 추가하지 않음
- 시간 태그 포함: `- [HH:MM] 작업 내용`

### Step 3: GitHub 커밋 + 푸시 (선택)

**조건**: git 저장소로 초기화된 경우에만 실행 (`git status` 오류 없을 때)

**동작**:
```bash
# 1. 상태 확인
git status

# 2. 모든 변경사항 추가
git add -A

# 3. 커밋 (자동 메시지)
git commit -m "docs: 세션 종료 - [주요 작업 요약]"

# 4. Pull (원격 동기화)
git pull origin main

# 5. Push
git push origin main
```

**커밋 메시지 규칙**:
- 작업 내용에 따라 prefix 자동 선택:
  - `feat:` 새 기능/스킬 개발
  - `fix:` 버그 수정
  - `docs:` 문서/기록 위주
  - `chore:` 설정/정리 위주
- 메시지에 주요 작업 1-2개 요약 포함

**제외 파일**:
- `.env` (보안)
- `node_modules/` (자동 생성)
- `__pycache__/` (자동 생성)

**git 미설정 시**: Step 3 스킵, Step 1-2 결과만 보고

## 규칙

**필수 규칙**:
- 세션 기록은 **실제 대화 내용 기반** (추측 금지)
- 데일리노트 기존 내용 보존
- 커밋 메시지는 작업 내용 반영
- 3단계 모두 완료 후 최종 보고

**예외 처리**:
- 변경사항 없으면 커밋 스킵
- git 미설정 시 Step 3 전체 스킵
- Conflict 발생 시 remote 우선 자동 해결
- 네트워크 오류 시 Step 1-2는 완료, Step 3만 재시도 안내
